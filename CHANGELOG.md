# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.2.0] - 2026-10-25

No changes since 1.2.0-rc1.

## [1.2.0-rc1] - 2026-10-25

### Changed
- Requires `iranimij/openfilter` ^1.2 and `iranimij/openfilter-hyva` ^1.2 (OpenFilter 1.2: path URLs, landing pages, load more and infinite scroll, quick filter bar, option images, dependent filters, All Products page, insights, migration from other filter modules, admin polish).

## [1.1.0] - 2026-10-16

No changes since 1.1.0-rc1.

## [1.1.0-rc1] - 2026-10-16

### Changed
- Requires `iranimij/openfilter` ^1.1 and `iranimij/openfilter-hyva` ^1.1 (OpenFilter 1.1: AND logic, price ranges, category tree, storefront modes, SEO templates, sitemap, GraphQL, REST).

## [1.0.0] - 2026-10-16

No changes since 1.0.0-rc1.

## [1.0.0-rc1] - 2026-10-15

### Added
- Metapackage requiring `iranimij/module-base` ^1.0, `iranimij/openfilter` ^1.0 and `iranimij/openfilter-hyva` ^1.0: OpenFilter on Hyvä in one `composer require`.
